# Multiplication Table Generator

A simple command-line **Multiplication Table Generator** built in Java. The program takes a number as input from the user and displays its multiplication table from **1 to 10**.

## 📌 Features

- 🔢 Accepts a number from the user
- ✖️ Generates the multiplication table from 1 to 10
- 💻 Simple and easy-to-use command-line interface
- ⚡ Fast and beginner-friendly Java program

## 🛠️ Technologies Used

- Java
- Scanner Class
- `for` Loop

## 🚀 How It Works

1. Run the program.
2. Enter a number.
3. The program prints the multiplication table from **1 to 10**.
